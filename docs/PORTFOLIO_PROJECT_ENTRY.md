# Portfolio Project Entry

## Conflict-Induced Displacement and Settlement Abandonment Detection

**Location:** Borno State, Nigeria  
**Analysis period:** 2015–2023  
**Theme:** Humanitarian GIS, conflict analysis, remote sensing and settlement planning

### Project Description

This project developed a multi-stage geospatial framework for detecting settlement contraction
and potential conflict-induced abandonment across Borno State.

The analysis integrated population change, built-up change, Landsat RGB imagery, NDVI, NDBI,
statistical screening and structured manual validation.

### Main Tasks

- harmonised 2,455 settlement records across 27 LGAs;
- integrated WorldPop population estimates for 2015 and 2023;
- calculated settlement-level population and built-up change;
- screened potential abandonment candidates;
- prepared paired Landsat imagery;
- assessed RGB, NDVI and NDBI changes;
- manually adjudicated 13 detailed cases;
- ranked settlement evidence;
- produced maps, figures, tables, a technical report and portfolio outputs.

### Key Results

- 5 probable-abandonment cases;
- 1 possible-abandonment case;
- 4 uncertain cases;
- 2 unsupported cases;
- 1 reconstruction or reoccupation case;
- no confirmed-abandonment case;
- Wumbi was the highest-ranked settlement.

### Tools

Python, Pandas, GeoPandas, Rasterio, Matplotlib, Landsat, WorldPop and Google Colab.

### Skills Demonstrated

Remote sensing, settlement-change detection, demographic analysis, evidence integration,
uncertainty assessment, humanitarian GIS, cartography and technical reporting.
