# Analysis Workflow

The public repository contains the validated project outputs, final data registers and methodology documentation.

The analysis was developed through a staged geospatial workflow using Python, GeoPandas, Google Earth Engine and supporting GIS tools. A cleaned standalone analysis script is not included because the original workflow was developed interactively rather than as a single publication-ready script.

The complete analytical method is documented in:

- `../05_Documentation/methodology.md`
- `../05_Documentation/data_sources.md`
- `../05_Documentation/limitations.md`

Only validated results are included in the repository.
