# Data Sources

| Dataset | Role in the Project |
|---|---|
| GeoNames populated places | Settlement locations and statewide screening |
| ACLED | Conflict-event exposure around settlements |
| VIIRS night-time lights | Change in detected night-time activity |
| Dynamic World and related satellite-derived built-up outputs | Built-signal change |
| WorldPop | Modelled population change |
| Borno State and LGA boundaries | Administrative and spatial context |

## Notes

### GeoNames

GeoNames settlement records were used to define the statewide settlement universe used in the screening.

### ACLED

ACLED records were used to describe recorded conflict exposure around settlements. Raw ACLED event data are not redistributed in this public repository.

### VIIRS

VIIRS night-time light data were used to assess whether detected night-time activity declined consistently through time.

### Dynamic World / Built-Up Evidence

Satellite-derived built-up information was used to assess physical change around settlements.

### WorldPop

WorldPop was used as modelled demographic evidence. It should not be interpreted as a direct settlement census.

### Administrative Boundaries

Borno State and LGA boundaries were used to provide spatial context for maps and LGA-level summaries.
