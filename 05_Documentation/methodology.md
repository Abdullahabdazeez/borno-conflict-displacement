# Methodology

## Overview

The project used a multi-indicator workflow to examine settlement change across Borno State between 2015 and 2023.

The analysis was designed to identify places where several independent datasets point to physical decline, reduced activity or demographic contraction. It was not designed to label settlements as abandoned from one dataset alone.

## 1. Settlement Screening

I started with 2,455 GeoNames settlement locations covering all 27 LGAs in Borno State.

Each settlement became a common analysis unit for comparing the different indicators.

## 2. Conflict Exposure

ACLED event records were used to measure conflict exposure around settlements.

For each settlement, the analysis summarised recorded conflict events within the defined settlement buffer and identified the year with the highest event count.

Conflict exposure was treated as context. It was not used as proof that conflict directly caused a specific settlement outcome.

## 3. Night-Time Lights

VIIRS night-time light data were used to examine changes in detected night-time activity.

The analysis tested whether a settlement showed temporally consistent decline across multiple time periods rather than relying on a single year-to-year difference.

## 4. Built-Up Change

Satellite-derived built-up information was used to examine changes in the built signal around settlements.

The analysis considered built probability change, built-area change and the direction of change through time.

Built-signal decline was treated as evidence of physical change, not direct proof of vacancy or abandonment.

## 5. Population Change

WorldPop data were used as demographic evidence.

Population change was classified into four interpretation groups:

- population decline
- population increase
- relatively stable population
- insufficient population evidence

Population decline strengthened a contraction interpretation. Stable or increasing population limited any simple abandonment claim.

## 6. Multi-Indicator Validation

The final stage compared the main evidence groups together:

- built-signal decline
- night-time light decline
- conflict exposure
- population decline

Thirteen locations were retained for detailed interpretation.

The final public-facing groups were:

- Priority contraction
- Priority change signal
- Retained change signal

## 7. Interpretation Rule

The final interpretation depended on agreement between indicators.

A strong decline signal in one dataset was not enough by itself. The project gave greater weight to locations where several independent indicators pointed in the same direction.

This is why the final output distinguishes settlement contraction/change evidence from confirmed abandonment.
